# Yalla Haul — Theme source notes

The complete merchant-editable Online Store 2.0 theme package is delivered as `yalla-haul-shopify-theme.zip` in ChatGPT and the user's Library. This repository branch carries documentation/source references and is not the binary upload bundle.

This version uses Yalla Haul's own Brand Guidelines: Yalla Red `#D7261E`, Haul Orange `#FF7A1A`, Ink `#121212`, Page Grey `#F6F6F4`, white surfaces, blush `#FDECEA`, DM Sans, 46px sentence-case buttons, 10px button corners, 14px cards and no gradients.

Use Shopify Theme Editor for global settings, section text/images/colors, logo/icon variants, menu, announcement ticker, header/footer, repeatable hero slides, category cards, featured collection tabs and add/remove/reorder sections. Upload the actual logo variants through Theme settings before publishing.

The theme package has structural JSON/schema validation, but Shopify Theme Check and live preview are still required after upload. The existing Next.js main branch and live site remain untouched.

# Haul Fresh — source notes

The complete uploadable theme is the ZIP delivered with this project. It contains Shopify's full Online Store 2.0 folder structure and the original bundled lifestyle images. This folder contains selected source snippets/settings for review, not a complete standalone install.

The visual brief follows the linked Voltix Fresh reference: high-energy lemon/lime color, giant condensed uppercase copy, product-first photography, a black announcement ticker, centered logo, playful collection cards and best-seller discovery. Copy and merchandising are customized for Yalla Haul's quirky home and personal-care finds; no Voltix theme source or product artwork is copied.

Install the ZIP as an unpublished theme first. The existing Next.js app and domain configuration are not changed or migrated.

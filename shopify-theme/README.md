# Haul Fresh — source notes

The complete uploadable theme is the ZIP delivered with this project. Its root contains Shopify's `assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, and `templates/` directories.

The visual brief for this version is based on the linked Voltix Fresh inspiration: high-energy lemon/lime color, giant condensed uppercase copy, product-first photography, a black animated ticker, centered logo, playful collection cards and prominent best-seller discovery. Copy and merchandising are customized for Yalla Haul's quirky home and personal-care finds; no Voltix theme source or product artwork is copied.

Install as an unpublished theme first. The existing Next.js app and domain configuration are not changed or migrated.
